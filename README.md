phishing campaign investigation from email triage to full
containment. Demonstrates proficiency in:

- Email header analysis (SPF/DKIM/DMARC)
- IOC extraction and threat intelligence enrichment
- Message trace and sign-in log correlation
- Impossible travel detection
- Incident containment and eradication
- MITRE ATT&CK mapping
- Professional SOC report writing
- Tools Referenced Wireshark · Splunk · VirusTotal · AbuseIPDB
